# LangChain Vector DB

Document ingestion and semantic search using LangChain + FAISS/Chroma.

## Stack
Python · LangChain · FAISS · OpenAI / Ollama

## Quickstart
```bash
pip install -r requirements.txt
python ingest.py      # embed and store docs
python query.py       # run semantic search
```

Set your `OPENAI_API_KEY` in `.env`.
